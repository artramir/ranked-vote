# Images Folder

Store candidate photos and party flags here.

## Structure

- `candidates/` - Candidate photos (200x200px recommended, under 50KB each)
- `flags/` - Party flags/logos (100x100px recommended, under 20KB each)

## Naming Convention

Use the party abbreviation in lowercase for consistency:
- `pln.jpg` for PLN candidate photo
- `pln.png` for PLN party flag

## Supported Formats

- Photos: `.jpg` or `.png`
- Flags: `.png` (for transparency) or `.jpg`

## Finding Images

- Official party websites
- Tribunal Supremo de Elecciones (TSE) website
- Wikipedia pages for parties/candidates
- News media sources

## Image Optimization

To keep files small:
- Resize to recommended dimensions
- Use online tools like TinyPNG, ImageOptim, or Squoosh
- Target: 20-50KB per image
