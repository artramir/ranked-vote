4. Ranked-choice recomputation logic (IRV)
Algorithm outline (backend)

On every submission:

Load all ballots

Initialize:

active_candidates = all candidates

round = 1

Loop:

For each ballot:

Assign it to the highest-ranked candidate still active

If none → ballot is exhausted

Count votes

If someone has >50% → stop

Else:

Eliminate candidate with fewest votes

Remove from active_candidates

Save round snapshot

round += 1

Important: multiple eliminations in preference chains

Your algorithm must skip eliminated candidates when reassigning ballots.
This happens naturally if you always scan the ranking list in order and check membership in active_candidates.

Determinism

You must define tie-break rules (even if rare):

Alphabetical

Fixed party order

Random but seeded

Define this now, even if you don’t expose it yet.

Step 3 — Implement ranked-choice logic (core logic)
Create backend/irv.py:
def compute_irv(ballots, candidates):
    active = set(candidates.keys())
    rounds = []

    while True:
        counts = {c: 0 for c in active}
        exhausted = 0

        for ballot in ballots:
            assigned = False
            for choice in ballot["ranking"]:
                if choice in active:
                    counts[choice] += 1
                    assigned = True
                    break
            if not assigned:
                exhausted += 1

        total_valid = sum(counts.values())

        for c, v in counts.items():
            if v > total_valid / 2:
                return {
                    "winner": c,
                    "rounds": rounds + [{
                        "counts": counts,
                        "eliminated": None
                    }]
                }

        eliminated = min(counts, key=counts.get)
        rounds.append({
            "counts": counts,
            "eliminated": eliminated
        })
        active.remove(eliminated)
